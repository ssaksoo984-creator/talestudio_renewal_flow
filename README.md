# Tale Studio 리뉴얼 플로우

리뉴얼(축소) 사용자 플로우와 화면 목업. 플로우차트와 목업이 같은 노드 ID를 쓴다.

- `index.html` — **프로토타입 (메인)**. 목업이 실제로 동작한다(입력·선택·생성 결과가 다음 화면까지 이어짐). 넓은 화면에서는 오른쪽에 플로우가 붙어 있고, 지금 화면이 빨간 그라데이션 테두리로 표시된다. 노드를 누르면 그 화면으로 이동한다. `index.html#A5`처럼 노드 ID로 바로 열 수 있다. 프로토타입 페이지라 `<!doctype>`/`<head>` 없이 쓰고, 게시할 때 감싸진다.
- `flow.html` — 플로우 문서. 단계별 플로우차트 + 노드 설명 + 검토 메모 + 작은 목업.
- `src/flow.js` — 플로우 데이터 (단계, 원칙, 노드, 엣지, 결정할 것, 오류 번호). **플로우를 바꿀 때는 여기만 고친다.**
- `src/screens.js` — 노드 ID별 화면 목업과 목업 상태·동작.
- `src/flowview.js` — 두 페이지가 함께 쓰는 플로우차트 그리기와 현재 노드 표시.
- `src/base.css` — 두 페이지가 함께 쓰는 색 토큰과 와이어프레임 스타일.
- `reference/` — 2026-10-13 인수인계 자료 원본.

## 노드 종류

| type | 뜻 |
|---|---|
| screen | 화면 |
| modal | 팝업 · 확인창 |
| decision | 예/아니오 · 갈림 |
| ai | AI 작업 중 — 화면 전체 잠금 |
| ext | 이번 범위 밖 (Director → Editor) |

엣지 kind: `yes` · `no` · `back`(롤백, 빨간 점선).

## 이번 기준 (2026-10-13)

Producer(아이디어 · 파일 · 장르·분위기 · 길이 · 바꿈 정도 · 화면 비율 🔒) → Writer(산문 작업공간) → 브레이크다운 → Artist(목록 → 스타일 🔒 → 생성 · 객체별 톤) → Storyboard(가칭, 기존 Writer 08~15 + 러프) → Director → Editor.
인물·배경을 늘리려면 산문으로 롤백. 인물·배경 상태는 Storyboard에서 롤백 없이 추가.

## 1안 / 2안 (Producer · Writer)

Producer와 Writer만 두 안으로 나눠 비교한다. 두 페이지 위쪽의 전환 버튼으로 바꾼다. Artist · Storyboard · Director는 두 안이 같다.

- **1안 · 화면에서 고르기** — Producer는 한 화면 폼(이야기 재료 · 장르·분위기 · 길이 · 바꿈 정도 · 🔒 화면 비율). Writer는 산문 위 조건 패널(러닝타임 · 장르·분위기 · 아이디어 소재 그대로/새롭게) + [AI 다시 쓰기], 채팅은 옆에서 자유 요청.
- **2안 · 채팅으로 만들기** — Producer는 아이디어를 보내면 에이전트가 장르·분위기 → 길이 → 바꿈 정도 → 화면 비율을 하나씩 묻는다(버튼 또는 말). 말에서 읽은 값은 건너뛰고, 위쪽 요약 칩으로 다시 물을 수 있다. Writer는 조건 패널 없이 채팅으로 고친다.
- 두 안 공통: 채팅에서 "다시 써줘" → "뭐가 마음에 안 드세요?" → 전부(조건 카드) / 일부분(문단 골라 그 부분만).

데이터에서는 노드·엣지의 `plan: 'A' | 'B'`로 나눈다 (`src/flow.js`).

## 바꿈 정도 (AI 개입 정도)

Producer 시작 화면에서 고른다. 단계마다 지키는 것과 바꾸는 것을 못박는다.

| 단계 | 이름 | 지켜요 | 바꿔요 |
|---|---|---|---|
| 1 | 그대로 | 문장 · 대사 · 장면 순서 · 결말 | 장면 나누기만 |
| 2 | 빈칸만 채우기 | 문장 · 대사 · 줄거리 · 결말 | 빠진 장소 · 인물 묘사 · 연출 |
| 3 | 다듬기 | 줄거리 · 인물 · 결말 | 문장 · 대사 · 장면 순서 |
| 4 | 새로 쓰기 | 소재 · 장르·분위기 · 길이 | 줄거리 · 인물 · 결말까지 |

1·2단계는 지킬 원문(글 파일 또는 60자 넘는 줄거리)이 있을 때만 열린다.
