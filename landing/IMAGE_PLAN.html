04

Claude에게 이미지 만들라고 할 때

다음 대화에서 아래 지시문을 그대로 붙여 넣으면 돼요.

landing/IMAGE_PLAN.md를 읽고 이미지를 만들어 줘.
1) 먼저 IMG-F1, F2, F3만 만들어서 보여 줘. 내가 고르면 그걸 기준 이미지로 써.
2) 고른 F1·F2·F3을 참고 이미지로 넣고 IMG-C1~C4를 만들어 줘. 얼굴·옷이 같아야 해.
3) 그다음 B1~B3, S1~S6.
- 모든 프롬프트 끝에 문서의 '스타일 꼬리'를 붙여 줘.
- 만들기 전에 모델과 크레딧 비용을 먼저 알려 줘.
- 결과는 landing/assets/img/<ID>.webp 로 저장(긴 변 1600px 이하, 품질 82).
- 저장하면 index.html과 dark.html의 같은 자리에 넣고 node build.mjs로 다시 빌드해 줘.

F 세트부터인물 얼굴이 먼저 정해져야 나머지 컷이 흔들리지 않아요.

참고 이미지 지원 모델얼굴이 이어지려면 이미지 레퍼런스를 받는 모델을 쓰라고 말하세요.

ID로 짚어 고치기"IMG-C3만 다시, 표정을 덜 놀라게"처럼 말하면 빨라요.

05

영상은 나중에 · 확정한 콘티에서 출발

영상은 확정한 콘티 이미지에서 출발(I2V)해요. "콘티 먼저, 확정 컷만 영상"을 페이지가 직접 보여 주는 셈이에요.

IMAGE_PLAN.md 4번 표대로 영상을 만들어 줘.
- I2V로, 출발 이미지는 landing/assets/img/<ID>.webp
- 720p로 먼저 1개(VID-C3)만 만들어 보여 줘. 괜찮으면 나머지.
- 생성 전에 모델과 비용을 먼저 알려 줘.
- 결과는 mp4(H.264, 무음) + 첫 프레임 webp로 저장하고,
  페이지에는 <video autoplay muted loop playsinline poster="..."> 로 넣어 줘.
- 영상은 HTML에 넣지 말고 같은 폴더 옆 파일로 둬.
  1. 영상 안에 글자나 로고가 생기면 다시 뽑아요.
  2. 쇼케이스 영상은 5~8초, 2MB 이하로 줄여요 (ffmpeg -crf 28 -an).
  3. 움직임 줄이기 설정이면 첫 프레임만 보여 줘요. 페이지에 이미 규칙이 있어요.
