# Lumi 페르소나 디자인 브리프 (v3)

Lumi는 **하얀 진주빛으로 시작해서, 단계마다 그 단계의 색과 소품을 입고, 작품이 완성되면 지금의 컬러 진주빛 Lumi가 되는** 캐릭터예요. 이 문서는 캐릭터 디자이너(사람이든 Claude든)에게 그대로 넘기는 브리프예요.

## 1. 모든 페르소나 공통 규칙

- **꼬리의 뜻**: Tale(이야기)과 tail(꼬리)은 소리가 같아요. 로고도 반쪽 T 아래로 꼬리가 뻗은 모양이고, Lumi는 그 꼬리를 가진 AI로 태어났어요. 그래서 꼬리는 절대 빼거나 줄이지 않아요
- **형태는 고정**: 머리와 몸이 하나인 말랑한 젤리, 왼쪽 아래로 흐르는 빛의 꼬리, 작은 세로 타원 눈 두 개. 입 · 팔 · 다리는 없어요. 원본: `mascot/assets/lumi-hd.webp`
- **바뀌는 것은 세 가지뿐**: ① 몸 색(단계 색 그라데이션) ② 소품 하나(머리 위에 얹거나 꼬리로 쥠) ③ 표정(눈 모양 · 기울기)
- **소품**: 실루엣만 봐도 알아볼 수 있는 단순한 형태. 몸 크기의 30~45%. 선(아웃라인) 없이 채움 형태. 소품 색은 그 단계 색의 진한 톤 + 크림 `#EDEAE0` 포인트
- **질감**: 지금 Lumi처럼 반투명 젤리 + 부드러운 광택. 흰 빛 번짐(글로우) · 흰 테두리 빛은 쓰지 않아요
- **크기 테스트**: 28px 채팅 아바타에서도 소품이 무엇인지 보여야 해요
- **산출물**: 투명 PNG 또는 WebP, 1536×1024, 정면, 모든 페르소나가 같은 위치 · 같은 크기. 28 · 40 · 120px 미리보기 함께

## 2. 시작 — 화이트 펄 Lumi

아직 색을 입지 않은 Lumi예요. 회색이 아니라 **하얀 진주빛에 연한 하늘이 비치는** 맑고 깨끗한 모습이에요. 홈 · 프로젝트 목록 · 첫 프로젝트를 만들기 전에 나와요.

| 항목 | 내용 |
|---|---|
| 몸 색 | 위 화이트 `#FFFFFF` → 가운데 펄 화이트 `#F4F6FB` → 아래 연한 하늘 `#CFE6F7` |
| 진주 광택 | 가장자리에 아주 옅은 라벤더 `#E4DEF7` · 민트 `#DDF3EF`가 비침 (채도 낮게) |
| 꼬리 | 연한 하늘 `#D8ECF8` → 투명 |
| 눈 | `#1F1E1D` |
| 빛 | 없음. 어두운 바탕에서는 연한 하늘빛 그림자 정도만 (흰 빛 번짐은 쓰지 않음) |
| 소품 | 없음 |
| 표정 | 맑고 준비된 표정. 눈이 살짝 위를 봄 |
| 완성 Lumi와 차이 | 같은 진주 재질. 시작은 거의 하얀 진주빛, 완성은 분홍 · 보라 · 하늘이 진하게 든 컬러 진주빛 |
| 주의 | 밝은 화면에서 묻히지 않게 아래쪽 하늘색으로 형태를 잡아 주세요 |

## 3. 단계 페르소나 6종

단계 색은 브랜드 그라데이션(Pearl Vivid)을 여섯 칸으로 나눈 색이에요.

| 단계 | 하는 일 | 대표 색 | 몸 그라데이션 (위 → 아래) | 소품 (필수) | 보조 디테일 | 성격 · 표정 |
|---|---|---|---|---|---|---|
| **Producer** | 기획 · 설정 | 오렌지 골드 `#F2A33A` | `#FFC966` → `#F2A33A` | 클립보드 (꼬리로 쥠) | 머리 위 작은 전구 반짝 | 활기차고 정리 잘하는 매니저. 눈을 크게 뜨고 살짝 앞으로 기울임 |
| **Writer** | 산문 쓰기 | 로즈 레드 `#E8606F` | `#FF8A9C` → `#E8606F` | 만년필 (꼬리로 쥠) | 둥근 동그라미 안경 | 생각 깊은 작가. 눈을 반쯤 감고 고개를 갸웃 |
| **Artist** | 인물 · 배경 그리기 | 바이올렛 `#8B63E8` | `#B07CFF` → `#8B63E8` | 빵모자(베레모) | 꼬리 끝 붓 + 몸에 작은 물감 자국 | 자유로운 화가. 한쪽 눈을 찡긋 |
| **Storyboard** | 콘티 · 컷 나누기 | 딥 블루 `#5A6AE6` | `#7A8BFF` → `#5A6AE6` | 머리 옆에 꽂은 연필 | 꼬리로 든 세 칸짜리 스케치 카드 | 꼼꼼한 설계자. 눈을 가늘게 뜨고 집중 |
| **Director** | 연출 · 촬영 지시 | 애저 `#3E9BE0` | `#5CC0FF` → `#3E9BE0` | 뒤로 쓴 감독 캡 | 꼬리 끝 작은 메가폰 | 자신감 있는 감독. 정면을 똑바로, 살짝 위로 고개 |
| **Editor** | 편집 · 마무리 | 민트 틸 `#2DB39A` | `#5FE3CB` → `#2DB39A` | 헤드폰 | 꼬리에 감긴 필름 스트립 | 차분한 마무리 담당. 눈을 편안하게 감고 리듬 타듯 기울임 |

공통 표정 세트(단계마다 같은 6종): 기본 · 듣는 중 · 생각 중 · 만드는 중 · 완료 · 오류

## 4. 완성 — 컬러 진주빛 Lumi (지금의 Lumi)

- **언제**: Editor까지 끝나 작품이 완성된 순간, 내보내기 완료, 홈 첫 화면 대표 이미지
- **모습**: 지금 원본 Lumi 그대로(분홍 · 보라 · 하늘이 섞인 진주빛). 소품 없음
- **전환 연출**: 화이트 펄 Lumi에 여섯 단계 색이 차례로 스며들어 컬러 진주빛으로 바뀜(약 1.6초). 마지막에 별 하나가 반짝
- **의미**: "모든 단계를 거친 Lumi = 테일의 색"

## 5. 성장 흐름

화이트 펄 Lumi → (Producer) 오렌지 골드 · 클립보드 → (Writer) 로즈 레드 · 만년필 → (Artist) 바이올렛 · 빵모자 → (Storyboard) 딥 블루 · 연필 → (Director) 애저 · 감독 캡 → (Editor) 민트 틸 · 헤드폰 → 컬러 진주빛 완성 Lumi

단계를 끝낼 때마다 그 단계 색이 꼬리 끝에 작은 빛 조각으로 남아요. 지나온 단계 수만큼 꼬리에 색이 쌓이면, 진주빛으로 바뀌기 직전의 "거의 완성된" 모습을 보여 줄 수 있어요(선택).

## 6. 채팅창(챗봇) 디자인 가이드

### 바뀌지 않는 것 (무채색 틀)

| 요소 | 값 |
|---|---|
| 채팅 패널 바탕 | `#1F1E1D` |
| Lumi 말풍선 | `#2A2927`, 글자 `#F5F4EE` |
| 내 말풍선 | `#34332F` |
| 빠른 답 칩 | `#3A3936` |
| 입력창 | `#30302E` |
| 보내기 버튼 | 크림 `#EDEAE0` + 진한 화살표 |

### 단계 색이 들어가는 곳 (지금 단계 색 하나만)

1. **아바타**: 그 단계 페르소나 Lumi 28px. 아바타 뒤에 단계 색 12% 원형 바탕
2. **채팅 머리**: "Lumi" 옆에 단계 이름 칩(단계 색 바탕 + 진한 글자 `#141312`). 예: `Lumi  [Writer]`
3. **말풍선 위 이름 "Lumi"**: 단계 색 글자
4. **생각 중 점 세 개 · 만드는 중 진행 막대**: 단계 색
5. **빠른 답 칩을 골랐을 때**: 단계 색 테두리 1.5px + 단계 색 18% 바탕
6. **입력창 포커스**: 단계 색 테두리 1px

### 단계가 바뀔 때

- 채팅 가운데에 작은 안내: "이제 **Writer Lumi**가 함께해요" + 페르소나가 옷을 갈아입는 짧은 애니메이션(0.8초)
- 아바타 · 칩 · 점 색이 한꺼번에 새 단계 색으로 바뀜

### 무채색 · 완성 상태

- 홈 · 프로젝트 목록: 단계 색 자리에 크림 · 회색
- 작품 완성: Lumi 말풍선 대신 진주빛 그라데이션 테두리 카드 "작품이 완성됐어요" + 진주빛 Lumi

### 하지 말 것

- 말풍선 전체를 단계 색으로 칠하기 (눈이 피로해요)
- 한 화면에 두 단계 색을 같이 쓰기
- 흰 빛 번짐 · 흰 테두리 빛
- 빨강을 강조색으로 쓰기 (오류에만 `#F24822`)

## 7. 다른 Claude에게 붙여 넣을 요청 문구

```
Tale Studio의 마스코트 Lumi 페르소나 8종을 디자인해 주세요.
첨부한 원본 Lumi(lumi-hd.webp)의 형태(젤리 몸 · 왼쪽 아래 빛의 꼬리 · 작은 세로 타원 눈 두 개, 입 · 팔 없음)는 그대로 두고,
몸 색 · 소품 하나 · 표정만 바꿔요.

1) 화이트 펄 Lumi: 화이트 #FFFFFF → 펄 화이트 #F4F6FB → 연한 하늘 #CFE6F7, 가장자리에 옅은 라벤더 · 민트 진주빛, 소품 없음, 맑고 준비된 표정
2) Producer: 오렌지 골드 #FFC966 → #F2A33A, 클립보드 + 머리 위 작은 전구

5) Storyboard: 딥 블루 #7A8BFF → #5A6AE6, 머리 옆에 꽂은 연필 + 세 칸 스케치 카드
6) Director: 애저 #5CC0FF → #3E9BE0, 뒤로 쓴 감독 캡 + 작은 메가폰

8) 완성 Lumi: 원본 컬러 진주빛 그대로, 소품 없음

규칙: 소품은 선 없는 채움 형태, 몸 크기의 30~45%. 반투명 젤리 질감과 부드러운 광택은 유지하되 흰 빛 번짐은 쓰지 않아요.

산출물: 투명 PNG 1536×1024, 정면, 모두 같은 위치 · 크기 + 28/40/120px 미리보기 한 장.
```
