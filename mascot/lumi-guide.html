에셋 분리 · 제작 방법

이 프로토타입이 할 수 있는 것과, 원본 이미지 수준을 내려면 추가로 필요한 것을 나눠 적었어요.

이 페이지의 Lumi는 레퍼런스의 A. Core Design을 보고 SVG로 다시 그린 벡터 버전이에요. 형태 · 색 · 움직임은 맞췄지만, 레퍼런스 이미지의 렌더링 질감(빛이 안에서 퍼지는 서브서피스, 젤리 굴절)과 픽셀 단위로 같지는 않아요. 원본과 같은 질감이 필요하면 아래 레이어를 디자이너가 따로 만들어 이미지로 바꿔 끼워야 해요. 레퍼런스 이미지 한 장을 잘라 쓰는 방법은 레이어가 한 덩어리라 눈 · 꼬리 · 빛을 따로 움직일 수 없어요.

  • 추천 방식: 지금처럼 SVG + CSS. 가볍고(라이브러리 없음, 그림 몇 KB), 아이콘 크기에서도 선명하고, 움직임 줄이기 설정을 따라요.
  • 원본 질감이 꼭 필요할 때: 3D 툴이나 일러스트 툴에서 위 표의 레이어를 따로 렌더해 투명 PNG/WebP(2배 해상도)로 받고, 같은 클래스의 SVG 레이어 자리에 <image>로 넣어요. 움직임 CSS는 그대로 써요.
  • Rive: 상태 전환을 디자이너가 직접 조율하고 싶을 때 좋아요. Rive 에디터에서 같은 레이어로 State Machine(idle · listening · thinking · creating · complete · error)을 만들어야 하고, 이 작업은 이 페이지만으로는 할 수 없어요.

Tale Studio 챗봇에 넣는 방법

저장소의 mascot/Lumi.js와 mascot/lumi.css 두 파일이면 돼요. 이 페이지에서 돌아가는 것과 같은 코드예요.

  1. 두 파일을 프로젝트에 복사하고, 앱 진입점에서 lumi.css를 한 번 불러와요.
  2. 챗봇 아바타 자리에 <Lumi size={40} state={state} />를 넣어요. 로딩 화면처럼 크게 보여 줄 곳에는 size={200} 정도로 써요.
  3. 챗봇 이벤트를 상태로 연결해요.
import Lumi from './mascot/Lumi';
import './mascot/lumi.css';

// 챗봇 이벤트 → Lumi 상태
//   입력칸에 포커스 · 타이핑        → 'listening'
//   메시지 보냄 · 첫 응답 기다림     → 'thinking'
//   산문 초안 · 그림 · 스토리보드 생성 중 → 'creating'
//   생성 끝                       → 'complete'  (1.4초 뒤 onDone → 'idle')
//   요청 실패 · 읽기 실패           → 'error'     (1.7초 뒤 onDone → 'idle')
function AgentHeader({ state, setState }) {
  return <Lumi size={40} state={state} onDone={() => setState('idle')} />;
}
  • 프로토타입 화면과 맞추면: 에이전트 채팅 머리글과 말풍선 아바타 → 40px. 생성 로딩 화면(산문 초안 E5, 산문 고치기 W2, 그림 만들기 A4, 스토리보드 준비 S0) → creating 200px. 오류 안내(E2e 읽기 실패 등) → error.
  • 움직임 줄이기: 운영체제 설정을 자동으로 따르고, 멈춰도 기본 상태 그림이 그대로 보여요.
  • React 버전: React 18 이상 (useId 사용). JSX 변환 없이도 동작해요.
