Lumi를 불러오는 중이에요…

먼저 알아 둘 점 · 해상도

받은 레퍼런스는 여러 그림을 모은 1536px 보드라서, 그 안의 Lumi는 가로 281px밖에 안 돼요. 채팅 아이콘(32~72px)과 중간 크기(200px 안팎)에서는 선명하지만, 그보다 크게 쓰면 흐려져요. lumi@2x.png는 같은 그림을 매끄럽게 2배로 키운 것이라 새 디테일이 생기지는 않아요. Lumi만 크게 렌더한 원본(가로 1000px 이상)이 있으면 같은 방법으로 다시 분리해 바꿔 끼울게요.

눈 · 꼬리를 따로 움직이려면

지금 에셋은 한 장이라서 눈 깜빡임이나 꼬리만 흔들기는 할 수 없어요. 아래처럼 레이어를 나눈 에셋이 먼저 필요해요. 이 작업은 아직 하지 않았어요.

레이어담을 것만드는 법붙일 움직임
1. 몸 (눈 없음)몸 · 하이라이트 · 안쪽 빛, 눈 자리는 주변 색으로 채움원본에서 눈을 지우고 그 자리를 몸 그라데이션으로 메움(포토샵 내용 인식 채우기 등)둥실거림 · 젤리 눌림
2. 왼쪽 눈 · 오른쪽 눈눈 하나씩, 테두리 옅은 빛까지원본 눈을 각각 잘라 따로 저장깜빡임 · 시선 · 오류 때 눌림
3. 빛의 꼬리꼬리 전체 + 몸 뒤로 숨는 뿌리 부분꼬리만 잘라내고, 몸에 가려진 뿌리는 이어서 그려 넣음. 몸 레이어에서는 꼬리를 지우고 몸 가장자리를 다시 그림흔들림 · 생성 중 넓어짐
4. 안쪽 빛 (선택)몸 안의 레드 · 핑크 빛 덩어리몸 레이어에서 빛만 따로 칠한 층생각 중 흐름 · 생성 중 순환
  • 모든 레이어는 같은 캔버스 크기 · 같은 위치로 저장해요(예: 1200×920 투명 PNG/WebP). 그래야 겹쳤을 때 원본과 똑같이 맞아요.
  • 가장 좋은 방법: 원본을 만든 도구(3D · 일러스트 · 생성 툴)에서 레이어별로 다시 뽑기. 원본 품질이 그대로 남아요.
  • 차선: 지금 이미지를 포토샵에서 리터치. 281px짜리라 눈을 지운 자리와 꼬리 뿌리를 손으로 그려야 해서 작은 크기에서만 자연스러워요.
  • 레이어 파일을 받으면, 같은 컴포넌트 안에서 몸 · 눈 · 꼬리를 겹쳐 놓고 눈 깜빡임과 꼬리 흔들림을 바로 붙일게요. 지금의 둥실거림 · 기울기 · 발광은 그대로 이어져요.

Tale Studio 챗봇에 넣기

저장소 mascot/의 LumiImage.js · lumi-image.css · assets/를 그대로 복사하면 돼요.

import LumiImage from './mascot/LumiImage';
import './mascot/lumi-image.css';

// 채팅 아바타
<LumiImage size={40} state={state} onDone={() => setState('idle')} />
// 생성 로딩 화면
<LumiImage size={200} state="creating" />

// 입력 중 'listening' · 응답 대기 'thinking' · 생성 중 'creating'
// 생성 끝 'complete' (1.4초 뒤 onDone) · 실패 'error' (1.3초 뒤 onDone)
  • 움직임 줄이기 설정이면 애니메이션을 멈추고 그림은 그대로 보여요.
  • 이미지 두 장(1배 71KB · 2배 149KB) 말고는 라이브러리가 없어요.
