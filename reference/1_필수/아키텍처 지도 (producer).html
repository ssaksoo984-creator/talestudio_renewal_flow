03 / Five-stage behavior flow

동작 로직 플로우차트

입력 → 실행 → 판정 → 산출물. 단계를 선택하면 전환·수정 조건을 확인합니다.

현재 코드열린 단계 재방문 가능 · Producer 잠금은 04의 목표 정책

UI와 Crew는 각각 실행 진입점입니다. 일부 승인·이동은 LLM 전에 처리합니다.

04 / People & journeys

Persona별 유저 저니

A는 가져온 자료에서 동료 인계까지, B는 아이디어에서 전체 결과까지.

목표 UX · 기획 초안
노드 클릭 → 사람·서비스·완료 기준

업무·승인자·인계는 대표 시나리오 가설입니다. 팀 권한과 자동화 구현 범위는 별도 설계합니다.

접수 ≠ 완료 ≠ 화면 반영. 채팅 Stop은 진행 중 LLM 응답을 중단하며 이미 제출된 서버 생성의 취소를 보장하지 않습니다. 이전 단계로 돌아가는 것만으로 생성·수정이 실행되지는 않습니다.
