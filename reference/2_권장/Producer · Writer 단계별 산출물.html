한눈에 · 입력 영향도

Producer 값이 어디까지 닿는지 · 기존과 제안

진한 보라는 Producer의 두 화면(P1 기초 세팅, P2 Producer 화면), 연한 보라는 거기서 정해 Writer로 넘기는 값입니다. 값은 아키텍처 지도 02(입력 영향도)를 따릅니다. 값을 누르면 그 값을 다루는 화면, 쓰는 Writer 단계, 이어서 바뀌는 다음 화면까지 표시됩니다. 제안(A안)에서 주황 값은 Artist에서, 파랑 값은 Writer에서 정하는 값입니다.

● 그 Producer 화면에서 이 값을 다룸● Writer 단계가 값을 직접 씀● 앞 단계 결과를 거쳐 영향을 받음◐ 처음값으로 한 번 넘김 · → 옮겨 감 · ✂ 여기서 끊김

Writer 쪽 연결은 이 문서의 단계 설명과 아키텍처 지도 02를, 기존 Producer는 아키텍처 지도 02와 실제 화면(10/12)을, 제안(A안)은 10/13 회의 결정 사항을 기준으로 정리했습니다. 코드에서 한 번 더 확인이 필요합니다.
