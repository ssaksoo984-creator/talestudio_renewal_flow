Real(실사) 렌더 결과

개구리 만수가 관절 인형(artist's mannequin)으로 바뀌어 있습니다. 원인은 러프 스토리보드 단계 — Writer가 그린 연필 스케치에서부터 이미 만수를 목각 인형처럼 그렸고, Director의 실사화(Real) 단계가 그 스케치를 "충실하게" 사진처럼 구현한 것입니다. 즉 실사화 엔진의 오류가 아니라, 앞 단계 스케치 오류를 그대로 승계하는 구조적 문제입니다.
재현: Director → 스토리보드 뷰 → Scene 1 · Shot 7 카드 더블클릭 → "연출 화살표 편집" 모달에서도 동일한 마네킹이 시작/중간/끝 3프레임 전부에 나타남 → Real 탭 최종 렌더에도 동일하게 반영됨.

"파리" 캐릭터로 등록했는데, Artist가 만든 캐릭터 시트는 꿀벌이고 실제 촬영 컷은 파리입니다.

캐릭터 시트(참조 이미지)와 실제 샷 생성 결과가 서로를 참조하지 않는다는 뜻입니다. Director의 실사화 단계는 캐스팅 시트가 아니라 장면 텍스트만 보고 매번 새로 상상해서 그리는 것으로 보입니다. 우연히 Shot 3은 "파리"라는 단어 덕에 그럴듯하게 나왔지만, 시트를 기준으로 한 일관된 캐릭터 유지가 전혀 보장되지 않습니다. 같은 문제가 "나비" 캐릭터(시트도 벌/나비 혼종 디자인)에서도 동일하게 관찰됩니다.

명명 혼란같은 그림, 이름이 4개

Writer가 만든 "러프 스토리보드"와 Director의 "Previz"는 사실 같은 그림입니다. 여기에 실제 파일명까지 더하면 이름이 4개가 됩니다.
Scene 1 · Shot 1 — 같은 샷, 두 가지 처리 단계
화면 라벨: "Previz"
실제 파일명: ..._rough_start_thumb.webp
Writer 화면에서 부르던 이름: "러프 스토리보드"
화면 라벨: "Real"
실제 파일명: ..._storyboard_start_thumb.webp
채팅 로그 표현: "촬영용 이미지" / API 명칭: storyboard_real_grid
연필 스케치
러프 스토리보드(Writer) = Previz(Director 토글) = 파일명 rough
실사 사진
Real(Director 토글) = 파일명 storyboard = 채팅에서는 "촬영용 이미지" = API는 storyboard_real_grid
가장 헷갈리는 지점은 "storyboard"라는 단어가 스케치가 아니라 사진 쪽 파일명에 붙어 있다는 것입니다. 영상 제작 상식과 정반대입니다. 사용자는 Writer 화면에서 "러프 스토리보드"를 배우고, Director에 오면 똑같은 그림이 "Previz"로 재명명되고, 실사 버튼을 누르면 진행 표시줄엔 "촬영용 이미지"라고 뜨는 3중 명명을 순서대로 겪게 됩니다.
이 3건은 스크린샷/원본 렌더 이미지로 직접 확인 가능한 것만 추렸습니다. 버튼 비활성화·토스트 원문 노출·채팅 확답 미반영 같은 나머지 항목은 이미지로 남기기 어려운(호버 상태·순간적 토스트) UI 버그라 이전에 드린 텍스트 리포트의 "분류 1~8"을 참고해 주세요.
